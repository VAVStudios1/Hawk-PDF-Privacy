Privacy Policy for Hawk PDF

Last updated: October 2, 2026

Hawk PDF is developed by VAV Studio. This privacy policy explains how Hawk PDF handles user information and files.

Data Collection

Hawk PDF does not require users to create an account and does not intentionally collect personal information.

PDFs, Images and Documents

Files selected by the user are processed locally on the user's device. Hawk PDF does not upload user PDFs, images, or documents to VAV Studio servers.

OCR

Hawk PDF includes optical character recognition functionality. OCR processing is performed on the user's device using an on-device text recognition model.

Internet Access

Hawk PDF is designed to operate without requiring internet access for its document processing features.

Advertising and Analytics

Hawk PDF does not contain advertising and does not use analytics or tracking services.

File Access

Hawk PDF accesses files selected by the user only for the purpose of performing requested PDF, document, image, or OCR operations.

Data Retention

Hawk PDF does not maintain a remote user database. Files and generated outputs remain on the user's device unless the user chooses to share, move, or delete them.

Data Sharing

VAV Studio does not sell or share user files or personal information with advertisers or third parties.

Children's Privacy

Hawk PDF is a general-purpose productivity utility and does not knowingly collect personal information from children.

Changes to This Privacy Policy

This privacy policy may be updated when Hawk PDF features or data handling practices change. Updates will be published on this page.
